# Layered licensing for `jam-actions-v1-probe`

The probe is built from the same three held-out songs as jam-actions-v1's test split and carries
the same layers and the same terms; see the companion dataset's `LICENSE-DATASET.md` for the full
statement.

1. **Compositions** — public domain (Joplin, 1899–1909).
2. **Arrangements** — the Mutopia Project's LilyPond typesettings, Public Domain, evidenced by each
   piece's Mutopia page and the file's creator event. No MIDI bytes are distributed; each take
   carries its render parameters and is re-rendered by the source repository's tests.
3. **These records** — released under **CC-BY-SA-3.0-DE** as part of the jam-actions-v1 collection,
   so the probe and the corpus carry one licence. Attribute the Mutopia Project and mcp-tool-shop-org
   (`CITATION.cff`); release derivatives share-alike; indicate changes.

The Hugging Face card declares `license: cc-by-sa-3.0`; the DE jurisdiction is documented here.

This set is evaluation-only: never split, never trained on, never merged into the corpus.
