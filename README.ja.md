## これは何ですか？

AIが演奏を学習するピアノとギター。シンセサイザーでも、MIDIライブラリでもありません。あくまで教育用の楽器です。

LLMはテキストを読み書きできますが、私たちが体験するように音楽を体験することはできません。耳もなければ、指もなければ、筋肉の記憶もありません。AI Jam Sessionsは、モデルが実際に使用できる感覚を与えることで、このギャップを埋めます。

- **読解** — 豊富な音楽的な注釈が付いた実際のMIDI楽譜。手書きの近似ではなく、解析され、分析され、説明されています。
- **聴覚** — 6つのオーディオエンジン（オシレーターピアノ、サンプルピアノ、ボーカルサンプル、物理的な声帯モデル、加算型ボーカルシンセ、物理モデリングされたギター）。これらがスピーカーから再生されるため、部屋にいる人々がAIの耳になります。
- **視覚** — ピアノロールは、演奏内容をSVG形式でレンダリングし、モデルが読み込んで検証できるようにします。インタラクティブなギタータブ譜エディター。視覚的なキーボード、デュアルモードノートエディター、チューニングラボを備えたブラウザの操作パネル。
- **記憶** — 複数のセッションにわたって保持される練習ジャーナルにより、時間の経過とともに学習が蓄積されます。
- **歌唱** — オペラソプラノから電子合唱まで、20種類の音声プリセットを備えた声帯合成。ソフィー、音程、および音節のナレーションを使用した一緒に歌うモード。

120曲すべての楽曲に、詳細な注釈が追加されました。歴史的背景、小節ごとの構造分析、重要なポイント、教育目標、パフォーマンスのヒントなど、すべての12ジャンルを網羅しています。このREADMEの以前のバージョンでは、生の楽曲は「AIがパターンを吸収し、音楽を演奏し、独自の注釈を作成するのを待っている」と記載されていました。まさにそれが起こったのです。注釈は、決定論的な曲ごとの分析（コード、反復構造、セクション境界、コンテンツ検証されたキー）に基づいてAIによって作成され、品質基準によって制御され、反対意見による事実確認が行われました。小節番号、コードウィンドウ、および構造カウントのすべてが、実際のMIDIに対して検証されてからリリースされました。

この作業の一環として、**[jam-actions-v0](#training-dataset)** — 実際のクラシックピアノを使用した115回の多段階MCPツール使用トレースを含む公開データセットも公開します。これは、単なるテキスト生成ではなく、シンボリック音楽における*実用的なツール使用*をLLMに教えるものであり、7軸のリリースゲートが付属しており、「証拠を伝える」ことと「タスクが些細なため合格とする」ことを区別します。詳細については、以下の[トレーニングデータセット](#training-dataset)を参照してください。

## ピアノロール

ピアノロールは、AIが音楽を見る方法です。任意の曲をSVG形式でレンダリングし、右手が青色、左手がコーラル色で表示され、拍子グリッド、ダイナミクス、小節の境界線が含まれます。

<p align="center">
  <img src="docs/fur-elise-m1-8.svg" alt="Piano roll of Fur Elise measures 1-8, showing right hand (blue) and left hand (coral) notes" width="100%" />
</p>

<p align="center"><em>Für Elise, measures 1–8 — the E5-D#5 trill in blue, bass accompaniment in coral</em></p>

2つのカラーモード：**手**（青/コーラル）または**音階**（クロマティックレインボー — すべてのCは赤、すべてのF#はシアン）。SVG形式であるため、モデルは画像を視覚的に確認できるだけでなく、マークアップを読み込んでピッチ、リズム、および手の独立性を検証できます。

## 操作パネル

このリポジトリの[`apps/cockpit`](apps/cockpit)にあるブラウザベースの作曲スタジオで、**[mcp-tool-shop-org.github.io/ai-jam-sessions/cockpit/](https://mcp-tool-shop-org.github.io/ai-jam-sessions/cockpit/)** でライブ実行できます。プラグインもDAWもインストールも不要です。すべてがブラウザ内に保存されます（作業内容はローカルに自動的に保存されます）。ハッキングしたいですか？

```bash
cd apps/cockpit && npm install && npm run dev   # Vite dev server, opens in your browser
```

- **デフォルトではサンプリングされたコンサートグランドピアノ** - コックピットには、トリミングされたSalamander Grandパック（90個のOGGファイル、8MB）が同梱されており、初回起動時にロードされ、シンセサイザーボイスと同じ出力チェーンを通じて再生されます。ロードされる前（またはオフライン時）には、調整されたオシレーターピアノがシームレスにカバーします。サンプルは[Alexander Holm](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html)によるもので、CC-BY 3.0のライセンスです。
- **パネルモード - リスニングルーム** - 実際のライブラリメロディーに対して、作曲エンジンのボイシングをペアで盲検的にA/Bテストします。音量調整されたクリップは、実際の音声パスを通じてオフラインでレンダリングされ、隠された下限の試行を含むシャッフルされた試行が行われ、ブートストラップ信頼区間を使用したブラッドリー・テリーランキングが適用され、正直な結果が得られます（すべてのペアが投票予算に達するまで一時的な状態であり、識別閾値を超えない場合は解釈できません）。2番目のサブモードでは、ローカルLLMジャッジを使用して同じランキングを実行し、両方の実行タイプ間で履歴を追跡し、比較ビュー（ケンダルのτ + エンジンランクのマッチ）を提供します。このビューは、安価なプロキシが人間の真実をどれだけ正確に反映しているかを評価します。
- **ビートに正確なトランスポート** - 音符は音楽的な時間軸で再生されるため、BPMコントロールは実際に再生時間を調整します。ドラッグして設定できるループ領域を持つ、クリックでシーク可能なタイムルーラーがあります。自動スクロール機能により、プレイヘッドを追跡できます。
- **録音開始時のキャプチャ** - QWERTYキー、画面上のキーボード、またはWeb MIDIデバイスを使用して演奏すると、スコアに記録されます。1小節のカウントイン、ループサイクル全体（または置換モード）でのルーパースタイルのオーバーダビング、量子化されたビューの下で生のパフォーマンスタイミングを保持し、各パスは元に戻せる単一の単位として扱われます。
- **完全なアンドゥ/リドゥ** - クリアやインポートを含むすべての編集操作が元に戻すことができます（Ctrl + Z）。ドラッグジェスチャーにより、実際の編集ツールと同様に操作が統合されます。
- **複数選択 + クリップボード** - 選択/描画ツールの切り替えの下で、長方形領域を選択できます。プラットフォーム標準の修飾キーをクリックしてコピー/カット/ペーストをプレイヘッドで行い、複製も可能です。
- **タッチ + アクセシビリティ** - すべてのサーフェスでキャプチャされたポインターイベントを使用します。ドラッグ操作の代替として、タップして再配置できます。キーボードを使用して音符を編集したり、色覚異常の人でも識別しやすいスコアオーバーレイを表示したりできます。
- **デュアルモードピアノロール** - インストルメントモード（クロマチックピッチクラスの色）とボーカルモード（母音の形によって色が付けられた音符：/a/ /e/ /i/ /o/ /u/）を切り替えることができます。
- **ビジュアルキーボード** - C4から2オクターブまで、QWERTYキーボードにマッピングされています。クリックまたは入力して操作します。
- **20個のボイスプリセット** - 15個のKokoroマップされたボイス（Aoede、Heart、Jessica、Sky、Eric、Fenrir、Liam、Onyx、Alice、Emma、Isabella、George、Lewis、および合唱とシンセサイザーボイス）、4個のトラクトマップされたボイス、および合成合唱セクションがあります。
- **10個のインストルメントプリセット** - サーバー側の6つのピアノボイスに加えて、シンセパッド、オルガン、ベル、ストリングスがあります。
- **音符インスペクター** - 任意の音符をクリックして、ベロシティ、母音、息遣いを編集します。
- **7つのチューニングシステム** - 平均律、純正調（長調/短調）、ピタゴラス音階、四分音差平均律、ヴェルクマイスターIII、またはカスタムセントオフセットを使用できます。調整可能なA4基準（392〜494 Hz）。
- **チューニング監査** - 周波数テーブル、ビート周波数分析を備えたインターバルトエスタ、およびチューニングのエクスポート/インポートが可能です。
- **スコアのインポート/エクスポート** - スコア全体をJSONとしてシリアライズし、ロードバックできます。
- **LLM対応API** - `window.__cockpit`は、`exportScore()`、`importScore()`、`addNote()`、`play()`、`stop()`、`panic()`、`setMode()`、および`getScore()`を公開するため、LLMがプログラム的に作曲、編曲、再生を行うことができます。

## 楽曲ライブラリ

実際のMIDIファイルから作成された12ジャンルにわたる120曲。各ジャンルには、歴史的背景、小節ごとの調和分析、重要なポイント、教育目標、およびパフォーマンスのヒント（ボーカルガイダンスを含む）を備えた、詳細な注釈が付けられた模範的な楽曲があります。これらの模範的な楽曲はテンプレートとして機能します。AIはまず1つを学習し、次に残りの楽曲に注釈を付けます。

| ジャンル | 模範的な楽曲 | キー | 教える内容 |
|-------|----------|-----|-----------------|
| ブルース | スリルは消え去り（B.B.キング） | Bマイナー | マイナーブルース形式、コール＆レスポンス、ビートの後ろで演奏 |
| クラシック | エリーゼのために（ベートーヴェン） | Aマイナー | ロンド形式、タッチの使い分け、ペダルの正確な操作 |
| 映画 | ある夏の日のコンプテンヌ（ティエルセン） | Eマイナー | アルペジオのテクスチャ、ハーモニーの変化なしでのダイナミックなアーキテクチャ |
| フォーク | グリーンスリーブス | Eマイナー | 3/4拍子のワルツ風、モーダルミクストゥーア、ルネサンス様式のボーカルスタイル |
| ジャズ | 枯葉（コスマ） | Gマイナー | ii-V-I進行、ガイドトーン、スウィングの8分音符、ルートレスボイシング |
| ラテン | イパネマの娘（ジョビン） | Fメジャー | ボサノヴァのリズム、クロマチックな転調、抑制されたボーカル |
| ニューエイジ | 君に流れゆく（イルマ） | Aメジャー | I-V-vi-IVの認識、流れるようなアルペジオ、ルバート |
| ポップ | イマジン（レノン） | Cメジャー | アルペジオによる伴奏、抑制、真摯なボーカル |
| ラグタイム | エンターテイナー（ジョプリン） | Cメジャー | 「オーム・パー」ベース、シンコペーション、多重セクション形式、テンポの正確さ |
| R&B | 迷信（スティーヴィー・ワンダー） | Ebマイナー | 16分音符のファンク、打楽器のようなキーボード、ゴーストノート |
| ロック | 君の歌（エルトン・ジョン） | Ebメジャー | ピアノバラードのボイスリーディング、転回形、会話のような歌い方 |
| ソウル | 私に寄りかかって（ビル・ウィザース） | Cメジャー | ダイアトニックなメロディー、ゴスペル風の伴奏、コール＆レスポンス |

曲は**生々しい**状態（MIDIのみ）から**注釈付き**の状態を経て、**演奏可能な状態**（音楽言語で完全に再生可能）へと進みます。AIは曲を研究し、`annotate_song`を使って注釈を作成することで、曲の普及を図ります。

## サウンドエンジン

6つのエンジンと、任意の2つを同時に実行できるレイヤードコンビネーターがあります。

| エンジン | タイプ | 音の特徴 |
|--------|------|---------------------|
| **Oscillator Piano** | 加算合成 | ハンマーノイズ、不協和音、ベロシティによって変化する明るさ、48ボイスのポリフォニー、ステレオイメージングを備えた多重ハーモニックピアノ。依存関係はありません。 |
| **Sample Piano** | サンプル再生 | Salamander Grand Piano - 本物です。**パックがインストールされている場合は、デフォルトで使用されるエンジン**（`samples/AccurateSalamander`または`AI_JAM_SAMPLES_DIR`）。npm tarballはサンプルを含まないため、[Salamander](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html)のダウンロードを提供する必要があります。ブラウザのコックピットには、独自のトリミングされた8MBパック（90個のOGGファイル、CC-BY 3.0 Alexander Holm）が同梱されており、Web上ではセットアップは一切必要ありません。 |
| **Vocal (Sample)** | ピッチシフトされたサンプル | ポルタメントとレガートモードを備えた持続的な母音のトーン。 |
| **Vocal Tract** | 物理モデル | ピンク・トロンボーン — 44セルのデジタル波導管を通るLFグロタル波形。4つのプリセット：ソプラノ、アルト、テノール、バス。 |
| **Vocal Synth** | 加算合成 | 15のココロボイスプリセット（フォルマントシェイピング、息遣い、ビブラート付き）。決定論的（シードされた乱数生成器）。 |
| **Guitar** | 加算合成 | 物理的にモデリングされた弦楽器 — 4つのプリセット（スチール・ドレッドノート、ナイロン・クラシック、ジャズ・アーチトップ、12弦）、8つのチューニング、17の調整可能なパラメーター。 |
| **Layered** | コンビネーター | 2つのエンジンをラップし、すべてのMIDIイベントを両方に送信します — ピアノ+シンセ、ボーカル+シンセなど。 |

### キーボードボイス

6つの調整可能なピアノボイスがあり、それぞれパラメータごとに調整可能です（明るさ、減衰、ハンマーの硬さ、デチューン、ステレオ幅など）：

| ボイス | 特徴 |
|-------|-----------|
| コンサートグランド | 豊かで、力強く、クラシック |
| アップライト | 暖かく、親密で、フォーク調 |
| エレクトリックピアノ | 滑らかで、ジャジーで、フェンダー・ローズのようなサウンド |
| ホンキートンク | デチューンされ、ラグタイム風、酒場風 |
| オルゴール | クリスタルクリアで、幽玄な音色 |
| ブライトグランド | 鮮やかで、現代的で、ポップ |

### ギターボイス

物理的にモデリングされた弦の合成を備えた4つのギターボイスプリセットがあり、それぞれ17の調整可能なパラメーター（明るさ、ボディ共鳴、ピッキング位置、弦のダンピングなど）があります。

| ボイス | 特徴 |
|-------|-----------|
| スチール・ドレッドノート | 明るく、バランスが取れており、クラシックなアコースティックギター |
| ナイロン・クラシック | 暖かく、柔らかく、丸みを帯びた音色 |
| ジャズ・アーチトップ | メロウで、木質的で、クリアな音色 |
| 12弦ギター | きらめくような、重ねられた、コーラスのようなサウンド |

## 練習日誌

各セッションの後、サーバーは発生したことを記録します — どの曲、どの速度、何小節、どれくらいの時間。AIは自身の考察を追加します — 何に気づいたか、どのようなパターンを認識したか、次に何を試すべきか。

```markdown
---
### 14:32 — Autumn Leaves
**jazz** | intermediate | G minor | 69 BPM × 0.7 | 32/32 measures | 45s

The ii-V-I in bars 5-8 (Cm7-F7-BbMaj7) is the same gravity as the V-i
in The Thrill Is Gone, just in major. Blues and jazz share more than the
genre labels suggest.

Next: try at full speed. Compare the Ipanema bridge modulation with this.
---
```

1日に1つのマークダウンファイルを作成し、`~/.ai-jam-sessions/journal/`に保存します。人間が読める形式で、追記のみ可能です。次のセッションでは、AIは日誌を読み、中断したところから再開します。

## トレーニングデータセット

**jam-actions-v0** — 実際のクラシックピアノMIDIに基づいた、複数ターンのMCPツール使用のトレースを含む公開データセット。このサーバーで使用されているライブラリから作成されたデータセットは、LLMに**シンボリック音楽に対する根拠のあるツール使用**を教えます — 単なるテキスト生成ではありません。

各レコードは、4小節のフレーズウィンドウと、注釈付きのティーチングターゲット、および*ターゲットトレース*（アシスタントが上記のMCPツール（`get_events_in_measure`、`get_events_in_hand`、`count_distinct_pitch_classes`、および残りの9つのMIDIインスペクターツールのセット）を使用して、フレーズを読み、分析し、議論するターンごとのセッション）をペアにします。

## ステータス

**v2.2.0 - 楽器に真の耳とリスニングルームが追加されたリリース**（[CHANGELOG](CHANGELOG.md)を参照）。コックピットのデフォルトピアノは、現在サンプリングされたコンサートグランドピアノです。これは、トリミングされたSalamanderパックであり、初回起動時にロードされ、準備ができるまで調整されたオシレーターシンセにフォールバックします。サーバーは、完全なパックがインストールされている場合にサンプルエンジンを自動的に選択します。その上には、**作曲パネル**があります。これは、盲検で音量調整されたA/Bリスニングルームであり、人間が作曲エンジンのボイシングを理論的に有効および無効なアンカーに対してランク付けします（ブートストラップCIを使用したブラッドリー・テリー、MUSHRAスタイルの識別閾値、一時的な状態と解釈できない状態の両方を主要な結果として扱います）。ローカルモデルパネルがあり、同じランキングをクロスファミリーのLLMジャッジを使用して実行し、比較ビュー（ケンダルのτ）を提供します。このビューは、安価なプロキシが人間の真実をどれだけ正確に反映しているかを評価します。

同じリリースには、パネルに供給する作曲エンジン（`src/compose/`：名前付きのスタイルプリセットを持つ決定論的なボイスリーディングゲート、構成によるメンバーシップボイシング仕様、一度に1つのパートを改良するリファイナー）、完全な健全性チェック（45件の問題が修正されました - セキュリティ通貨、人間味のあるストリングス、外観を維持した視覚的な修正）、Mutopiaのパブリックドメインバイトから再調達されたサティとドビュッシーのライブラリエントリ、および見知らぬ人によるテストの強化が含まれます。これには、記述的な検証エラー、構造化された`{code, message, hint}`エラーエンベロープ、キュレーションされたtarball、長時間のツールの進行状況通知、およびCLIエラー文法が含まれます。ライブサーフェスには**49個のツールと4つのプロンプトテンプレート**があり、**3,033個のテストに合格し（1つはスキップされました）**。**公開状態：**npmの最新バージョンは**2.0.0**です。それ以降のものはすべて、2.2.0リリースまで`main`に存在します。現時点では、クローンから実行してください。

v2.1.0 — アナリストが**クリエイター**になったリリース（[CHANGELOG](CHANGELOG.md)を参照）。作曲ループは製品として提供されます。モデルがライブラリの任意の楽曲のコード変更を提案し、プラットフォーム独自の決定論的ツールがそれをゲートします — コードエンジンは、意図したすべてのボイシング（`verify_harmony`）を確認する必要があり、すべてのメロディーノートは新しいハーモニーに対してラベル付けされ、検証された解釈のみが `add_song` → `play_song` → `view_piano_roll` に進みます。生成は構築によって検証されます — ルーブリックや自己評価はありません。ジャムの概要を作成するのと同じ `inferChord` が審査員です。 `maker_loop` プロンプトテンプレートは、ループ全体をガイドします。

## セキュリティとプライバシー

**アクセスされるデータ：** 楽曲ライブラリ（JSON + MIDI）、ユーザーの楽曲ディレクトリ（`~/.ai-jam-sessions/songs/`）、ギターのチューニング設定、練習日誌のエントリ、ローカルオーディオ出力デバイス。

**アクセスされないデータ（デフォルトパス）：** MCPサーバーとCLIはネットワーク接続を行わず、認証情報を読み取らず、ユーザーの楽曲ディレクトリ以外のシステムファイルにもアクセスしません。テレメトリーは収集または送信されません。同じパッケージに含まれる**オプトイン式のデータセット/評価ツール**（`scripts/run-llm-eval.ts`、プロベナンス検証ツール）だけが例外です。明示的に実行した場合に限り、LLM APIを呼び出すことができ（環境から`ANTHROPIC_API_KEY`を読み取りますが、保存することはありません）、プロベナンスURLを取得します。これは、サーバー、CLI、またはインストールのいずれかのコンポーネントとして実行されることはありません。

**権限：** MCPサーバーはstdioトランスポートのみを使用します（HTTPは使用しません）。CLIはローカルファイルシステムとオーディオデバイスにアクセスします。完全なポリシーについては、[SECURITY.md](SECURITY.md)を参照してください。
